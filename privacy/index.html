網站經營與聯絡方式

本網站提供海牛排 Hi Steak 的餐點、門市與用餐資訊。若有本網站或資料使用相關問題，可於營業時間致電 04-3609-8099，或至 台中市南屯區南屯路二段721-1號 與門市聯繫。

瀏覽本網站

你不需要註冊會員即可瀏覽。本版網站未設置會員、留言、線上訂位、付款或蒐集姓名與電話的表單，也未在網站程式中內建 Google Analytics、廣告像素或跨站行銷追蹤碼。

網站使用 Cloudflare 提供網頁傳遞與網路安全服務。為提供連線、維護安全或排除異常，網路服務提供者可能處理 IP 位址、請求時間、瀏覽器資訊、所請求網址等技術資料，並可能依安全需要使用 Cookie。其處理地區、保存與運作方式依提供者的實際服務及政策。

上述技術處理與透過本網站主動填寫個人資料不同；本網站沒有要求你填寫個人資料才能查看菜單。更多服務商資料處理說明可參閱 Cloudflare 隱私權政策。

網站流量與效能統計

目前網站的 Cloudflare 託管設定另載入 Web Analytics，用於了解瀏覽次數與網頁載入效能。依 Cloudflare 的產品說明，這類統計不使用 Cookie 或 localStorage 蒐集使用量，也不以瀏覽器指紋辨識個人；這與前述網路安全服務的技術處理不同。工具與資料說明可參閱 Cloudflare Web Analytics。

電話洽詢與外部平台

點擊電話連結會開啟裝置的撥號功能，不會由本網站自動送出訂單。若你選擇來電詢問訂位或預訂餐點，請只提供處理該次需求必要的聯絡與用餐資訊；實際處理方式可在提供資料前向門市確認。

本網站提供 Google Maps、Instagram 與 Uber Eats 的外部連結。只有當你選擇開啟連結時，才會前往該平台；本版不內嵌地圖或社群追蹤元件。你在外部平台的帳號、定位、付款、訂單與訊息，適用各平台的隱私政策及服務條款。

若你想查詢、閱覽、取得複本、補充、更正或請求停止蒐集、處理、利用或刪除與你相關的個人資料，可透過上述電話與門市聯繫，說明請求範圍；處理時可能需要確認身分，並依適用規定及實際持有資料的情況辦理。由外部平台持有的資料，亦可直接透過該平台的隱私管道提出。
